# 🌐 مراقب النت الذكي v2.9 - (By Mahmoud_Kamal) - Android 14 APK

## خطوات بناء وتحميل ملف الـ APK عبر GitHub مجاناً (بدون تثبيت أي برامج)

1. فك الضغط عن ملف **`Morakeb-V2.9-Android14-GitHub.zip`** في مجلد فارغ على جهازك.
2. افتح موقع GitHub وأنشئ مستودعاً جديداً عبر الرابط: [https://github.com/new](https://github.com/new)
   - اكتب اسم المستودع مثلاً: `morakeb-net-apk`
   - اضغط **Create repository**.
3. في الصفحة التالية اضغط على الرابط الأزرق الصغير: **`uploading an existing file`**.
4. اسحب وأفلت **جميع المجلدات والملفات المستخرجة** داخل المربع:
   - `.github` (مهم جداً لأنه يحتوي على ملف البناء التلقائي)
   - `app`
   - `build.gradle`
   - `settings.gradle`
   - `gradle.properties`
   - `README.md`
5. اضغط الزر الأخضر **Commit changes** بالأسفل.
6. اذهب إلى تبويب **Actions** في أعلى صفحة المستودع على GitHub.
7. ستجد عملية البناء **`Build Android APK`** تعمل تلقائياً (تستغرق حوالي 90 ثانية حتى تظهر علامة ✅ الخضراء).
8. اضغط على عنوان عملية البناء بعد اكتمالها، وانزل لأسفل الصفحة عند قسم **Artifacts** واضغط على **`Morakeb-Net-V2.9-Android14-APK`** لتحميل ملف الـ `.apk` وتثبيته على هاتفك الأندرويد.
